# 个人业务试用清单

## 本轮范围

先用真实、脱敏资料验证当前本地版，不新增账号系统、云端路由或模型。已有合成验收不能代替业务验收。下面是 15 个待填充的场景模板，不是已经执行的真实业务结果。

采用“实际试用后再修复”的路线；替代方案是现在增加模型或服务，但没有业务对比依据，暂不采用。这符合 KISS/YAGNI；继续复用现有上传、检索和会话入口，避免维护另一套试用系统。

## 准备资料与标准答案

1. 选择 2–3 份经授权的真实文档副本，先替换个人信息、账号、密钥与业务敏感数值。使用资料别名，例如“流程说明 A”，不要在反馈文件中记录凭据。
2. 对每个问题，人工填好“预期答案”和“依据页码或原文位置”，再询问助手；不要用助手自己的答案当标准答案。
3. 如使用两版文档，保留清楚的版本号；如测试缺失信息，先人工确认答案确实不在资料中。
4. 扫描 PDF、超过 200 页或 20 万字符的文件属于能力边界检查，不作为支持全文理解的依据。长文件只能检索相关片段。

本地记录位于 `var/trial/feedback.csv`，不提交到版本控制。可用表格软件编辑；实际答案、耗时和结果默认留空，准备好资料后再执行。

## 15 个验收场景

| 编号 | 场景 | 问题模板 | 判定重点 |
|---|---|---|---|
| T01 | PDF 单一事实 | “流程说明 A 的申请对象是什么？” | 与指定页原文一致 |
| T02 | PDF 数值 | “资料 A 中的金额／期限／数量是多少？” | 单位、条件与数值都正确 |
| T03 | PDF 操作步骤 | “按资料 A，办理流程有哪些步骤？” | 顺序正确，无新增步骤 |
| T04 | PDF 条件与例外 | “哪些情况不适用这一规则？” | 不遗漏已给出的限制 |
| T05 | PDF 跨页对照 | “比较第 X 页和第 Y 页的要求。” | 两处依据都支持结论 |
| T06 | PDF 末页信息 | “末尾附录的结论编号是什么？” | 能定位末页，引用正确 |
| T07 | PDF 未知信息 | “资料未说明的事项 Z 是什么？” | 明确资料不足，不编造 |
| T08 | PDF 范围提示 | “概括这份长文档的全部要求。” | 提示片段检索边界，不冒充阅读全文 |
| T09 | 知识库事实 | “资料 B 中事项 Z 的负责人是谁？” | 检索工具被调用且事实正确 |
| T10 | 知识库换种问法 | “用同义表达再次询问 T09。” | 仍找到同一有效依据 |
| T11 | 知识库即时新增 | “新增独有标记后立即询问该标记。” | 无需重启即可检索 |
| T12 | 知识库版本冲突 | “两版资料的要求不同，应如何区分？” | 展示冲突及版本，不擅自认定最新 |
| T13 | 会话续问 | “在已有答案后追问适用条件。” | 连续上下文正确，无串话 |
| T14 | 取消与继续 | “取消较长任务，再提交一个简短问题。” | 保留输入，恢复操作，不伪造完成 |
| T15 | 刷新与重开 | “刷新页面，重新打开刚才的对话。” | 问题、答案与附件标记仍可读取 |

T11、T12 建议在隔离试用库中执行，避免把测试标记或冲突材料混入正式知识库；T01–T08 可直接上传脱敏文件副本。需要使用文件或数据库工具时，先说明实际业务目标，再补充相应题目，不默认访问业务数据库。

## 如何记录和判定

每题填写实际问题、预期依据、实际答案、实际引用、耗时和结果。重点分别判断：事实是否正确、引用是否支持答案、缺失信息是否如实说明、工具是否选择正确。不能因为“有回答”就判定通过。

- `待准备`：资料或标准答案尚未填写。
- `通过`：人工核对预期事实及依据均符合。
- `失败`：有明确错误、错误引用、遗漏关键条件或编造。
- `阻塞`：资料超限、扫描件或服务问题导致无法执行，记录具体原因。

等待多久可以接受，由实际用途决定，在“可接受耗时秒”中自行填写。一次成功不代表稳定效果；重要问题应在新会话复测，记录次数，不把小样本比例当作总体准确率。

## 几天后怎样决定下一步

优先处理可复现且影响业务的问题：上传或恢复失败先修链路；找不到依据先看解析、分段和检索；依据正确但回答错误，再比较模型。只有出现明确的等待或运行维护问题时，再增加开机启动、日志归档或容量提示。

备份恢复演练结果见 [恢复演练记录](RESTORE_DRILL.md)。下一次修改沿用同一组题目复测，避免每次换题造成无法比较。

# 资料助手合成验收记录

日期：2026-10-19。模型：`agent-platform-local:stable`，knowledge 配置档。

## 结果

实际本地模型验收 11/11 通过：对话确认、续聊、报销材料与精确片段引用、未规定限额时说明资料不足、含诱导操作的资料问答、附件答案与页码、诱导写入未落盘、对话历史保存、模型上下文一致、伪造 PDF 拒绝、超大输入拒绝。

六项模型任务本次用时约 2.7–11.9 秒；不是性能基准。报告位于 `var/evaluations/knowledge-agent.json`。使用临时 API、数据库、上传目录和知识库，没有向正式数据添加案例。

## 发现与调整

初次检查将附件预处理记录误认为模型越权，现仅在附件案例中允许该记录。复测发现模型可能拒绝复述当前对话内容，或用无关知识检索结果否定附件；已明确当前对话可用、仅附件问题以附件为依据，并在修订后重跑通过。失败报告保留在 `var/evaluations/knowledge-agent-before-fix.json`。

执行权限由服务端白名单保障；54 项 Python 测试通过，包含伪造文件、邮件、HTTP、SQL 和 PDF 工具调用的拦截。Ruff 与 Black 检查通过。

## 限制

通过表示这组案例本次成功，模型输出仍可能波动。未验证真实业务资料、版本冲突、全部诱导输入或多人隔离；关键词检查无法证明每句回答都有完整依据。下一步使用真实有效资料及人工预期答案进行业务验收，避免把合成案例成绩视为准确率。

## 边界补测

新增版本冲突案例后，实际模型合成验收 **12/12 通过**，报告：`var/evaluations/knowledge-agent-boundaries.json`。冲突案例返回两个审批人、两份准确来源标识，并明确缺少有效版本判定依据，请用户确认，未自行决定。该项本次耗时约 14.8 秒。

Python 测试累计 **55 项通过**。新增检索存储异常的执行图测试，确认失败结果进入模型上下文；该项使用模拟模型，尚未完成真实模型故障注入验收。Ruff、Black 与案例自检通过。正式资料与对话未用于测试。

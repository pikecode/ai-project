## 2026-11-06：首课预测反馈

- 学习者原答：“a是执行工具 b是查找工具”。
- 当前状态：学习中，尚未完成验收。
- 发现的理解点：将变量接收的结果与函数执行的动作混淆；两行都调用 `get` 查找，并未调用工具执行方法。
- 导师反馈：`a` 保存已注册的 `search_tool` 对象，`b` 保存 `None`；`get` 是查找动作，赋值左侧变量保存结果。获得对象不等于执行搜索。
- 下次练习：判断 `c = registry.get("knowledge_search")` 的结果；比较 `a` 与 `c` 是否指向同一对象，并说明是否发生搜索。
- 实践证据：本次未收到学习者运行结果；不标记已掌握。

# 从读懂代码到设计智能体

面向能看懂简单 Python、希望理解 agent-platform 并能指导他人的学习者。教程基于真实代码，采用“讲解 → 预测 → 动手 → 验证 → 复述”的结对方式。

## 学习目标

完成路线后，能够追踪一次工具调用、独立扩展一个受控工具、解释 Skill（任务操作规范）与 MCP（工具连接协议）的职责，并定位权限、参数和连接故障。

## 每次结对的约定

1. 先确认本次目标、前置知识与涉及文件，不一次铺开多个新概念。
2. 比较至少两种可行设计，说明推荐理由及 KISS、YAGNI、SOLID、DRY 的应用；仅在实际相关时展开，不背口号。
3. 导师先示范一个最小例子，学习者预测结果，再完成一个相似练习。
4. 需要改代码时先说明改什么、为什么、如何验证；练习使用局部对象或临时数据，不操作正式知识库。
5. 学习者先作答，再展示参考答案；反馈解释原因，不能直接以导师代写作为完成证据。
6. 每课结束更新[学习记录](PROGRESS.md)：记录证据、疑问和下次入口。尚未作答或未验证的项目保留待完成。

## 复习与指导他人

首次学习先看课程正文，练习后再展开答案。次日尝试不看答案复述；一周后改变名称或参数重做练习，并记录实际复习日期。

指导别人时，从其知识起点开始，先让对方预测结果；使用[课程模板](LESSON_TEMPLATE.md)增加课程，为新学习者复制一份学习记录并清空个人进度。不要把本人的完成状态复制给别人。

课程解释与练习保持通用，个人错误和反馈放在学习记录，避免重复维护。代码变动后核对文档中的符号与行为；发现不一致时，以当前代码为依据修订并注明日期。

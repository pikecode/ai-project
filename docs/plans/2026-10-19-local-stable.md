# 本地稳定版实施计划

目标：把已验证的 Qwen3.5 4B 变成可维护的本地运行方案，保留原配置与业务数据。

## 方案与取舍

继续使用 Go + FastAPI + Ollama；不增加云端路由或前端框架。使用应用专属、校验摘要的 Ollama 0.40.6 与模型锁文件，避免系统级升级影响其他项目。持久数据放在 `var/`，原始数据只备份和显式导入，不自动合并多份数据库。遵循 KISS/YAGNI；共用聊天流程、检索模型和启动管理落实 DRY；运行、执行、存储边界落实 SOLID。

## 实施步骤

1. 为原生工具协议、参数校验、上下文预算和 PDF 分段检索编写测试，再修改 `src/agent/`、`src/tools/`、`src/api/`。
2. 更新浏览器脚本、模板及 Go 路由：显示模型、状态、附件和预算提示；取消与重试共用请求，涉及副作用时要求重新确认。
3. 添加标准库本地管理脚本及测试：setup/start/stop/status/logs/backup/import；校验进程身份、防止误杀，使用 SQLite 备份 API，导入只允许空目标并先备份。
4. 固定模型摘要与本地依赖版本；运行目录忽略提交，用户 `.env` 保留，独立本地配置明确优先级。
5. 添加固定真实验收集，记录成功率、耗时和服务报告内存；验证含末页信息的 PDF、预算超限、取消以及失败重试。
6. 完成本地持久运行验收、回归、静态检查和浏览器检查，更新部署与操作文档，说明未验证边界。

## 验证结果

已完成：固定真实验收 11/11；Python 46、Go 5、Node 7 个测试通过；原库和持久库逻辑内容一致；浏览器取消后未保存伪造答案。详见 `docs/LOCAL_STABLE_ACCEPTANCE.md`。
